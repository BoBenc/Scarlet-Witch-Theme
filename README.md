</div>

| English | Magyar |
|---------|--------|

## 🚀 Getting Started /  Kezdő lépések 🚀

</div>

| English | Magyar |
|---------|--------|
| 1. **Install** the extension from the VS Code Marketplace<br>2. **Activate** the theme: `File → Preferences → Themes → Color Theme → Scarlet Witch (Dark) / Scarlet Witch (Light)`<br>3. **Enjoy** the magical coding experience! ✨ | 1. **Telepítsd** a bővítményt a VS Code Marketplace-ről<br>2. **Aktiváld** a témát: `File → Preferences → Themes → Color Theme → Scarlet Witch (Dark) / Scarlet Witch (Light)`<br>3. **Élvezd** a varázslatos kódolási élményt! ✨ |
